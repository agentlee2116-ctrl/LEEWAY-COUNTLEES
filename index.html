COUNTLEES

A local-first Windows desktop review candidate for system measurements and careful file management.

Download source ZIP View source on GitHub

What it does

System health

Displays local disk and platform measurements, with optional CPU and memory telemetry.

File review

Scans a folder selected by you and classifies older temporary files for review.

Recoverable cleanup

Moves eligible temporary files into a recovery folder; it does not permanently delete them.

Verified ZIP

Creates a standard ZIP archive and checks its contents against the source hash.

Run the desktop app

Download and extract the source ZIP, then use a Windows terminal in the extracted folder. Install Python 3.12+ with Tk support first.

py -m pip install -r requirements.txt
py countlees.py

Or launch Launch-CountLees.cmd. The app runs on your computer and stores account data locally.

Important: Pages hosts this site, not the app

GitHub Pages serves static websites. It cannot run this Python/Tkinter desktop application. This page provides project information and a source download; CountLees itself must be launched on a compatible computer.

Review candidate — limitations

  • No cloud accounts, email verification, or password recovery. Local sign-in is not an operating-system security boundary.
  • Only selected .tmp/.temp files older than one day are eligible for recoverable quarantine. This does not immediately free disk space.
  • Compression is standard ZIP, not LeeWay Formula compression; originals are retained.
  • Maintenance settings are links to native Windows settings, not automatic optimization.
  • Android/iOS are not implemented. This candidate is not independently verified or production qualified.
